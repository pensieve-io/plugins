# Credential formats safe to mask in any text: provider keys with a fixed prefix
# and alphabet, private keys and passwords embedded in URLs. Nothing here keys
# on a label such as "password", so business documents, where "password-
# protected" and accounts tables are common, never misfire.
#
# One rule per line: an identifier, a tab, then a Python regular expression,
# compiled with re.ASCII. The match is replaced by the mask marker; a `keep`
# group before it and a `tail` group after it survive. `\\?_` admits the
# backslash Markdown converters put before an underscore.
#
# The Pensieve server imports this file at a pinned commit
# (backend/scripts/sync_credential_formats.py), so edit it here.
# The search for a private key's end stops at the next header, so a run of
# repeated headers cannot rescan the text.
# Formats adapted from OpenCrawl and Gitleaks: see THIRD_PARTY_NOTICES.md.
